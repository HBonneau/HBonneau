## Featured project

[**Learning electrolyte dynamics**](https://github.com/HBonneau/electrolyte-memory-surrogates)

Given an electric-field history, predict the current. This Python and PyTorch study compares regression, causal GRUs, and a physical model reduction. It tests why accurate predictions can still miss slow relaxation.

Includes simulation data, controlled loss experiments, saved models, and automated tests.
