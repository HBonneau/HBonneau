### Featured project

[**Learning electrolyte dynamics**](https://github.com/HBonneau/electrolyte-memory-surrogates) — a reproducible study of causal GRUs and physical model reduction. I built a simulation-to-training pipeline and tested why accurate current predictions can still miss slow physical relaxation. Includes regression baselines, controlled loss experiments, saved models, and automated tests.
